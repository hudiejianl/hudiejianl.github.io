L3-012 水果忍者

2010 年风靡全球的“水果忍者”游戏，相信不少人都玩过（没玩过也没关系）。游戏中会随机弹出水果和炸弹，玩家需要尽可能切掉水果并避开炸弹来完成任务。如果能一刀切中一连串水果，还会有额外奖励，如图 1 所示。

图 1

现在我们把问题抽象成一个几何模型。将游戏世界看作二维平面：

  • 每个水果简化为一条 竖直线段（垂直于 x 轴）
  • “一刀切下”简化为：是否存在一条 直线 能穿过所有线段

也就是说，我们要找一条直线，使其与每条竖直线段都有交点（穿过端点也算切中）。

图 2

如图 2 所示，绿色竖线段表示水果；灰色虚线表示一条可行的“刀法”（直线），它能穿过所有线段。

另外约定：若直线恰好经过线段端点，也视为切中该水果。问题就变成：在保证有解的前提下，如何构造出这样一条直线，并输出其上任意两个整点。

输入格式：

输入在第一行给出一个正整数 N（≤10^4），表示水果的个数。随后 N 行，每行给出三个整数 x、y1、y2（空格分隔），表示一条端点为 (x, y1) 和 (x, y2) 的竖直线段，其中 y1 > y2。

注意：输入保证一定存在一条可以穿过全部线段的直线，不需要考虑无解情况。坐标是区间 [−10^6, 10^6) 内的整数。

输出格式：

在一行中输出穿过所有线段的直线上、具有 整数 坐标的任意两点 p1(x1, y1) 和 p2(x2, y2)，格式为：

x1 y1 x2 y2

注意：本题答案不唯一，由特殊裁判判定，但一定存在四个坐标全是整数的解。

输入样例：

5

-30 -52 -84

38 22 -49

-99 -22 -99

48 59 -18

-36 -50 -72

输出样例：

-99 -99 -30 -52

分析

题目保证存在一条满足条件的直线。可以用“端点构造 + 斜率约束”的思路来理解：

  1. 将一条可行直线向下平移，直到它恰好经过某条竖线段的一个端点。
  2. 以这个端点为轴微小旋转，可行解会在某个临界位置经过另一条竖线段的端点。

因此可以认为：一定存在一条可行直线，经过 两条不同竖线段的端点（上端点或下端点）。

枚举某条竖线段的端点作为基准点，并对其它线段维护“允许斜率范围”的交集（最大斜率 kmax 与最小斜率 kmin）。只要范围不为空，就说明存在可行直线；找到后按要求输出任意两点即可。

#include<iostream>
#include<algorithm>
using namespace std;
const int N=100010,INF=0x3f3f3f3f;
struct node
{
    int x,y1,y2;
}arr[N];
bool cmp(node x,node y){return x.x<y.x;}
int main()
{
    int n;cin>>n;
    for(int i=1;i<=n;i++)cin>>arr[i].x>>arr[i].y1>>arr[i].y2;
    sort(arr+1,arr+n+1,cmp);
    for(int i=1;i<=n;i++)
    {
        bool flag=true;
        double kmax=INF,kmin=-INF;//初始化斜率正负无穷 
        double tmax,tmin;//要求的两点之间的斜率最大值和最小值 
        int x,y;//确定第二个端点的坐标 
        for(int j=1;j<=n;j++)
        {
            if(i==j)continue;
            if(i<j)
            {
                tmax=(double)(arr[j].y1-arr[i].y1)/(arr[j].x-arr[i].x);
                tmin=(double)(arr[j].y2-arr[i].y1)/(arr[j].x-arr[i].x);
            }
            else
            {
                tmax=(double)(arr[i].y1-arr[j].y2)/(arr[i].x-arr[j].x);//最大斜率 
                tmin=(double)(arr[i].y1-arr[j].y1)/(arr[i].x-arr[j].x);//最小斜率 
            }
            //端点选哪个无所谓,第二个端点选上还是下无所谓,扩大或者缩小就顺便修改一下 
            if(kmax>tmax)kmax=tmax,x=arr[j].x,y=arr[j].y1;
            if(kmin<tmin)kmin=tmin,x=arr[j].x,y=arr[j].y2;
            if( kmax<kmin )//说明这个点做上端点了,换一个点 
            {
                flag=false;
                break;
            }
        }
        if(flag)
        {
            cout<<arr[i].x<<' '<<arr[i].y1<<' '<<x<<' '<<y<<'\n';
            break;
        }
    }
    return 0;
}
