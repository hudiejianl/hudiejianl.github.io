L3-014 周游世界

周游世界是件浪漫事，但规划旅行路线就不一定了…… 全世界有成千上万条航线、铁路线、大巴线，令人眼花缭乱。所以旅行社会选择部分运输公司组成联盟，每家公司提供一条线路，然后帮助客户规划由联盟内企业支持的旅行路线。本题就要求你帮旅行社实现一个自动规划路线的程序，使得对任何给定的起点和终点，可以找出最顺畅的路线。所谓“最顺畅”，首先是指中途经停站最少；如果经停站一样多，则取需要换乘线路次数最少的路线。

输入格式：

输入在第一行给出一个正整数N（≤100），即联盟公司的数量。接下来有N行，第i行（i=1,⋯,N）描述了第i家公司所提供的线路。格式为：

M S[1] S[2] ⋯ S[M]

其中M（≤100）是经停站的数量，S[i]（i=1,⋯,M）是经停站的编号（由4位0-9的数字组成）。这里假设每条线路都是简单的一条可以双向运行的链路，并且输入保证是按照正确的经停顺序给出的 —— 也就是说，任意一对相邻的S[i]和S[i+1]（i=1,⋯,M−1）之间都不存在其他经停站点。我们称相邻站点之间的线路为一个运营区间，每个运营区间只承包给一家公司。环线是有可能存在的，但不会不经停任何中间站点就从出发地回到出发地。当然，不同公司的线路是可能在某些站点有交叉的，这些站点就是客户的换乘点，我们假设任意换乘点涉及的不同公司的线路都不超过5条。

在描述了联盟线路之后，题目将给出一个正整数K（≤10），随后K行，每行给出一位客户的需求，即始发地的编号和目的地的编号，中间以一空格分隔。

输出格式：

处理每一位客户的需求。如果没有现成的线路可以使其到达目的地，就在一行中输出“Sorry, no line is available.”；如果目的地可达，则首先在一行中输出最顺畅路线的经停站数量（始发地和目的地不包括在内），然后按下列格式给出旅行路线：

Go by the line of company #X1 from S1 to S2.
Go by the line of company #X2 from S2 to S3.
......

其中Xi是线路承包公司的编号，Si是经停站的编号。但必须只输出始发地、换乘点和目的地，不能输出中间的经停站。题目保证满足要求的路线是唯一的。

输入样例：

4

7 1001 3212 1003 1204 1005 1306 7797

9 9988 2333 1204 2006 2005 2004 2003 2302 2001

13 3011 3812 3013 3001 1306 3003 2333 3066 3212 3008 2302 3010 3011

4 6666 8432 4011 1306

4

3011 3013

6666 2001

2004 3001

2222 6666

输出样例：

2

Go by the line of company #3 from 3011 to 3013.

10

Go by the line of company #4 from 6666 to 1306.

Go by the line of company #3 from 1306 to 2302.

Go by the line of company #2 from 2302 to 2001.

6

Go by the line of company #2 from 2004 to 1204.

Go by the line of company #1 from 1204 to 1306.

Go by the line of company #3 from 1306 to 3001.

Sorry, no line is available.

分析

本题是一个典型的 多条件最短路径：

  1. 最少经停站数（等价于最少经过的边数；最后输出时不包含起点与终点，所以答案是“边数 - 1”）
  2. 若经停站数相同，则 最少换乘次数（换乘=相邻两段区间所属公司不同）

题目还要求输出路线时：

  • 只能输出 起点、换乘点、终点
  • 每一段需要输出使用哪家公司的线路

题目保证最优解唯一。

1) 建模

把每个站点看成图的节点。对于每家公司给的线路 S1 S2 ... SM：

  • 对每一对相邻站点 (Sj, Sj+1) 建一条 双向边
  • 这条边属于公司 i（后续计算换乘要用）

由于站点编号是 4 位字符串，建议用 unordered_map<string,int> 做离散化映射到 [0..V-1]。

边的存储建议：

  • adj[u] 存若干条 {v, companyId}
  • 题目说每个运营区间只承包给一家公司，所以同一条相邻站点边的 company 是确定的

2) 为什么“只用经停站数”会超时

如果优先队列（Dijkstra）里只记录“到达某站的最少边数”，那么当边数相同时，无法利用“换乘次数”做有效剪枝：

  • 你可能会多次以相同边数到达同一站点，但来自不同公司
  • 这些状态在后续扩展时会产生不同换乘代价
  • 如果不把它们区分并用更强的判定更新，队列里会堆积大量无效状态，容易 TLE

因此正确且稳定的做法是：把 换乘次数也纳入最短路的比较，并在状态中携带“上一段所用公司”。

3) 状态设计（推荐写法）

只用 dist[站点] 会丢信息：同一站点、同样的边数下，“最后乘坐的公司不同”会导致后续换乘次数不同。

因此建议把状态扩展为：

  • dist[u][c] = (edges, transfers)
  • 表示到达站点 u 且最后一段乘坐公司为 c 时的最优代价

比较规则是 字典序最小：先 edges，再 transfers。

4) 路径记录与输出（只输出起点/换乘点/终点）

在更新 dist[v][nc] 时同步记录父指针：

  • preNode[v][nc] = u
  • preComp[v][nc] = c

回溯出完整路径后，再按“公司变化点”切段输出。

经停站数量输出：

  • 若最短路径边数为 edges，则经停站数（不含起点终点）为 edges - 1

5) 参考实现（C++）

#include <bits/stdc++.h>
using namespace std;

struct Edge {
    int v;
    int comp;
};

struct State {
    int u;
    int last;
    int edges;
    int trans;
};

struct Cmp {
    bool operator()(const State& a, const State& b) const {
        if (a.edges != b.edges) return a.edges > b.edges;
        return a.trans > b.trans;
    }
};

static const int INF = 1e9;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;

    unordered_map<string, int> id;
    vector<string> rid;

    auto getId = [&](const string& s) -> int {
        auto it = id.find(s);
        if (it != id.end()) return it->second;
        int x = (int)rid.size();
        id[s] = x;
        rid.push_back(s);
        return x;
    };

    vector<vector<Edge>> adj;
    auto ensure = [&](int x) {
        if ((int)adj.size() <= x) adj.resize(x + 1);
    };

    for (int i = 1; i <= N; i++) {
        int M;
        cin >> M;
        string prev;
        cin >> prev;
        int u = getId(prev);
        ensure(u);
        for (int j = 1; j < M; j++) {
            string cur;
            cin >> cur;
            int v = getId(cur);
            ensure(v);
            adj[u].push_back({v, i});
            adj[v].push_back({u, i});
            u = v;
        }
    }

    int K;
    cin >> K;
    while (K--) {
        string S, T;
        cin >> S >> T;
        if (!id.count(S) || !id.count(T)) {
            cout << "Sorry, no line is available.\n";
            continue;
        }

        int s = id[S], t = id[T];
        int V = (int)adj.size();

        vector<vector<int>> distE(V, vector<int>(N + 1, INF));
        vector<vector<int>> distT(V, vector<int>(N + 1, INF));
        vector<vector<int>> preNode(V, vector<int>(N + 1, -1));
        vector<vector<int>> preComp(V, vector<int>(N + 1, -1));

        priority_queue<State, vector<State>, Cmp> pq;
        distE[s][0] = 0;
        distT[s][0] = 0;
        pq.push({s, 0, 0, 0});

        while (!pq.empty()) {
            auto cur = pq.top();
            pq.pop();
            int u = cur.u, last = cur.last;
            if (cur.edges != distE[u][last] || cur.trans != distT[u][last]) continue;
            for (auto e : adj[u]) {
                int v = e.v, nc = e.comp;
                int ne = cur.edges + 1;
                int nt = cur.trans + ((last != 0 && last != nc) ? 1 : 0);
                if (ne < distE[v][nc] || (ne == distE[v][nc] && nt < distT[v][nc])) {
                    distE[v][nc] = ne;
                    distT[v][nc] = nt;
                    preNode[v][nc] = u;
                    preComp[v][nc] = last;
                    pq.push({v, nc, ne, nt});
                }
            }
        }

        int bestC = -1;
        for (int c = 1; c <= N; c++) {
            if (distE[t][c] == INF) continue;
            if (bestC == -1 || distE[t][c] < distE[t][bestC] ||
                (distE[t][c] == distE[t][bestC] && distT[t][c] < distT[t][bestC])) {
                bestC = c;
            }
        }

        if (bestC == -1) {
            cout << "Sorry, no line is available.\n";
            continue;
        }

        vector<int> nodes;
        vector<int> comps;
        int cu = t, cc = bestC;
        while (!(cu == s && cc == 0)) {
            nodes.push_back(cu);
            comps.push_back(cc);
            int pu = preNode[cu][cc];
            int pc = preComp[cu][cc];
            cu = pu;
            cc = pc;
        }
        nodes.push_back(s);
        reverse(nodes.begin(), nodes.end());
        reverse(comps.begin(), comps.end());

        int edges = (int)nodes.size() - 1;
        cout << max(0, edges - 1) << "\n";

        int i = 0;
        while (i < edges) {
            int company = comps[i];
            int j = i;
            while (j < edges && comps[j] == company) j++;
            cout << "Go by the line of company #" << company
                 << " from " << rid[nodes[i]] << " to " << rid[nodes[j]] << ".\n";
            i = j;
        }
    }

    return 0;
}

6) 复杂度

状态规模约为 V * (N+1)，Dijkstra 的复杂度约为：

  • O((V*N + E*N) log (V*N))

在本题约束下可以通过。

7) 常见坑点

  1. 第一段不算换乘：只有 last != 0 && last != nc 才 +1。
  2. 输出经停站数：是 edges - 1（不含起点终点）。
  3. 输出只包含起点/换乘点/终点：用“公司变化点”切段。
