Hexo 搭建与使用指南（含常用命令）

2026/2/19 教程 Hexo Blog

1. Hexo 是什么

Hexo 是一个基于 Node.js 的静态博客框架：

  • 写作时用 Markdown
  • 生成时把内容编译成静态 HTML/CSS/JS
  • 部署时把 public/ 推到 GitHub Pages、Vercel、服务器等

适合做个人博客、笔记站点、技术文档。

2. 准备环境

你需要：

  • Node.js（建议 LTS）
  • 包管理器（pnpm/npm/yarn 任选其一）
  • Git（如果要部署到 GitHub Pages）

检查版本：

node -v
pnpm -v
git --version

3. 初始化一个 Hexo 博客

3.1 全局安装 Hexo CLI（可选）

如果你习惯全局命令：

pnpm add -g hexo-cli

之后可以直接用：

hexo -v

如果你不想全局安装，也可以用 pnpm exec hexo ...（下面命令会同时给两种写法）。

3.2 新建站点

hexo init my-blog
cd my-blog
pnpm install

启动本地服务：

hexo server
# 或者：pnpm exec hexo server

默认访问：

  • http://localhost:4000/

4. 项目结构速览

常见目录：

  • source/：你的内容
    • _posts/：文章（每篇一个 .md）
    • 例如：about/index.md：页面（Page）
  • themes/：主题
  • _config.yml：站点主配置（title、url、主题、部署等）
  • public/：生成后的静态文件（部署用）

5. 写作：新建文章与页面

5.1 新建文章

hexo new post "我的第一篇文章"
# 或者：pnpm exec hexo new post "我的第一篇文章"

生成文件位置：

  • source/_posts/我的第一篇文章.md

5.2 新建页面（例如 about）

hexo new page about
# 或者：pnpm exec hexo new page about

生成目录：

  • source/about/index.md

6. 常用命令清单（最常用）

6.1 本地预览

hexo server
# 或者：pnpm exec hexo server

常用参数：

  • -p 4001：换端口
  • -o：启动后自动打开浏览器

6.2 清理缓存

当你发现页面没更新、主题资源异常时，先清理：

hexo clean
# 或者：pnpm exec hexo clean

6.3 生成静态文件

hexo generate
# 或者：pnpm exec hexo generate

输出目录：

  • public/

6.4 部署

hexo deploy
# 或者：pnpm exec hexo deploy

通常会把 public/ 推送到你配置的远程仓库/分支。

7. 配置：你最常改的几个点

站点根配置在 _config.yml，常见字段：

  • title：站点标题
  • subtitle：副标题
  • description：描述（部分主题会显示）
  • url：你的站点域名（GitHub Pages 一定要正确）
  • theme：主题名（themes/ 目录下的文件夹名）

固定链接：

permalink: :year/:month/:day/:title/

8. 主题：安装与切换

8.1 安装主题

常见方式：

  • 下载主题到 themes/<theme-name>/
  • 在 _config.yml 里设置：
theme: <theme-name>

8.2 主题配置

大多数主题会在 themes/<theme-name>/_config.yml 提供主题专属配置（菜单、头像、背景、评论等）。

9. 部署到 GitHub Pages（一键部署）

如果你使用 hexo-deployer-git，流程一般是：

  1. 安装部署插件
pnpm add -D hexo-deployer-git
  1. 配置 _config.yml
deploy:
  type: git
  repo: git@github.com:<username>/<username>.github.io.git
  branch: main
  1. 执行部署
hexo clean && hexo generate && hexo deploy

如果你像我这个仓库一样在 package.json 配了脚本，也可以直接：

pnpm clean
pnpm build
pnpm deploy

10. 常见问题

10.1 部署时报权限错误

如果 repo 用的是 SSH（git@github.com:...），要确认：

  • 你本机已经配置 SSH key
  • GitHub 已添加公钥

10.2 改了内容但页面没变

按顺序排查：

  • hexo clean
  • hexo generate
  • 重新 hexo server 看本地是否正常

更新并推送到仓库

  • hexo d -g
