L3-020 至多删三个字符

给定一个全部由小写英文字母组成的字符串，允许你至多删掉其中 3 个字符，结果可能有多少种不同的字符串？

输入格式：

输入在一行中给出全部由小写英文字母组成的、长度在区间 [4, 10^6] 内的字符串。

输出格式：

在一行中输出至多删掉其中 3 个字符后不同字符串的个数。

输入样例：

ababcc

输出样例：

25

提示：

  • 删掉 0 个字符得到 ababcc。
  • 删掉 1 个字符得到 babcc、aabcc、abbcc、abacc、ababc。
  • 删掉 2 个字符得到 abcc、bbcc、bacc、babc、aacc、aabc、abbc、abac、abab。
  • 删掉 3 个字符得到 abc、bcc、acc、bbc、bac、bab、aac、aab、abb、aba。

分析

朴素想法是：对每个字符枚举“删/不删”，从而得到所有可能的结果字符串。但字符串长度可达 10^6，这种做法显然会超时。

可以用动态规划统计“不同结果字符串”的数量。设 dp[i][j] 表示：考虑前 i 个字符（即 s[0..i-1]），恰好删除 j 个字符时，能够得到的不同字符串个数。

不考虑去重时，转移类似于二项式计数：

dp[i][j] = dp[i-1][j] + dp[i-1][j-1]

含义分别是：

  • 不删 s[i-1]：从 dp[i-1][j] 继承
  • 删 s[i-1]：从 dp[i-1][j-1] 继承

但这里的关键是：上述加法会对某些结果字符串产生重复计数。

去重思路

当当前位置 i 之前存在一个与 s[i] 相同的字符 s[j]（j < i）时，如果我们把 (j, i) 之间的所有字符都删除掉，那么结果字符串中这两个相同字符会“贴”在一起。此时，“保留 s[i]”与“保留 s[j]”可能产生相同的结果，从而造成重复。

为了处理这类重复，记录 pre[i] 为 s[i] 上一次出现的位置（不存在则为 -1）。若 pre[i] = j，并且我们删除了 i-j 个字符把它们贴在一起，则需要减去这部分重复贡献，对应到转移就是：

dp[i][k] -= dp[j][k-(i-j)]

这也正是代码中 pre 与减法项的含义。

参考实现（C++）

#include<bits/stdc++.h>
using namespace std;

typedef long long ll;

string s;
int pre[1000005];
ll dp[1000005][5];

ll dfs(int i,int flag){
    if(i<0){
        return flag==0;
    }
    if(dp[i][flag]!=0){
        return dp[i][flag];
    }
    ll res=dfs(i-1,flag);
    if(flag>0){
        res+=dfs(i-1,flag-1);
    }
    if(pre[i]!=-1 and flag-(i-pre[i])>=0){
        res-=dfs(pre[i]-1,flag-(i-pre[i]));
    }
    return dp[i][flag]=res;
}

int main() {
    cin>>s;
    map<char,int> flag;
    memset(pre,-1,sizeof(pre));
    for(int i=0;i<s.size();i++){
        if(flag.count(s[i])){
            pre[i]=flag[s[i]];
        }
        flag[s[i]]=i;
    }
    int n=s.size();
    dp[0][0]=1;
    for(int i=1;i<=n;i++){
        for(int j=0;j<4;j++){
            dp[i][j]=dp[i-1][j];
            if(j>0){
                dp[i][j]+=dp[i-1][j-1];
            }
            if(pre[i-1]!=-1 and j-(i-1-pre[i-1])>=0){
                dp[i][j]-=dp[pre[i-1]][j-(i-1-pre[i-1])];
            }
        }
    }
    cout<<dp[n][0]+dp[n][1]+dp[n][2]+dp[n][3];
    return 0;
}

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：O(n)
