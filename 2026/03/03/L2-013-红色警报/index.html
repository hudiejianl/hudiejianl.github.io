L2-013 红色警报

L2-013 红色警报

战争中保持各个城市间的连通性非常重要。本题要求你编写一个报警程序，当失去一个城市导致国家被分裂为多个无法连通的区域时，就发出红色警报。注意：若该国本来就不完全连通，是分裂的k个区域，而失去一个城市并不改变其他城市之间的连通性，则不要发出警报。

输入格式：

输入在第一行给出两个整数N（0 < N ≤ 500）和M（≤ 5000），分别为城市个数（于是默认城市从0到N-1编号）和连接两城市的通路条数。随后M行，每行给出一条通路所连接的两个城市的编号，其间以1个空格分隔。在城市信息之后给出被攻占的信息，即一个正整数K和随后的K个被攻占的城市的编号。

注意：输入保证给出的被攻占的城市编号都是合法的且无重复，但并不保证给出的通路没有重复。

输出格式：

对每个被攻占的城市，如果它会改变整个国家的连通性，则输出Red Alert: City k is lost!，其中k是该城市的编号；否则只输出City k is lost.即可。如果该国失去了最后一个城市，则增加一行输出Game Over.。

输入样例：

5 4

0 1

1 3

3 0

0 4

5

1 2 0 4 3

输出样例：

City 1 is lost.

City 2 is lost.

Red Alert: City 0 is lost!

City 4 is lost.

City 3 is lost.

Game Over.

分析

这题可以采用“倒序恢复城市”的离线思路：

  1. 先把所有将被攻占的城市标记为不可用，用剩余城市建图并初始化并查集。
  2. 然后按被攻占顺序的逆序逐个“恢复”城市，把它与当前仍可用的邻居做合并。
  3. 对于恢复的这个城市，统计它当前可连接到的连通块数量：
    • 若数量大于 1，说明当初失去它会导致连通块数增加，需要输出红色警报。
    • 否则只输出普通提示。

代码

for(int i=0;i<n;i++){
        fa[i] = i;
}

for(int u=0;u<n;u++){
    if(blocked[u]) continue;
    for(int v : g[u]){
        if(blocked[v]) continue;
        merge(u, v);
    }
}

vector<string> ans;
if(k==n){
    ans.emplace_back("Game Over.");
}
for(int i=k;i>0;i--){
    set<int> f;
    for(int y:g[solve[i]]){
        if(!blocked[y]){
            int ff=find(y);
            f.insert(ff);
        }
    }
    blocked[solve[i]]= false;
    for(int y:g[solve[i]]){
        if(blocked[y]) continue;
        merge(y,solve[i]);
    }
    if(f.size()>1){
        ans.push_back("Red Alert: City " + to_string(solve[i]) + " is lost!");
    }else{
        ans.push_back("City " + to_string(solve[i]) + " is lost.");
    }
}
for(int i=ans.size()-1;i>=0;i--){
    cout<<ans[i]<<endl;
}

return 0;
